Design system

The single, light-theme language behind every PostForge screen — documented so it stays consistent.

Key choices. Emerald as primary makes the product’s core promise — verification — literal: the brand colour is the same green that means “checked.” The pipeline is visualised as a horizontal stepper of six coloured agents so progress reads left-to-right at a glance. Finished posts switch to an editorial serif (Newsreader) so they feel like real articles, not app UI.
